# ウチマモ 設計仕様書

作成日: 2026-08-19  
対象: 完全無料で開始する「工事不要・後付け家庭防犯」専門Webサービス＋アフィリエイトメディア

## 1. 結論

「ウチマモ」は、一般的な記事ブログではなく、以下を統合した防犯商品選定サービスとして構築する。

1. 防犯診断
2. 商品検索・絞り込み
3. 最大3商品の比較
4. 条件別ランキング
5. 商品詳細
6. SEO記事
7. 楽天アフィリエイト自動リンク
8. ASPリンク管理

公開基盤は独自ドメインを購入せず、Cloudflare Pages の `*.pages.dev` を使用する。収益が発生するまで、初期費用・月額費用ともに0円を必須条件とする。

## 5. 楽天連携

Cloudflare側のSecret/環境変数へ以下を設定する。

```text
RAKUTEN_APP_ID
RAKUTEN_ACCESS_KEY
RAKUTEN_AFFILIATE_ID
```

GitHubリポジトリへ実値をコミットしない。

楽天市場商品検索APIから商品名、商品URL、アフィリエイトURL、商品画像、価格、レビュー、ショップ名、アフィリエイト料率等を取得する。APIは毎画面表示時に呼ばず、同期処理で商品キャッシュJSONを作成し、Astroから静的配信する。

ウチマモ独自ランキングはアフィリエイト料率ではなく、条件一致率・商品適合度・機能・価格等を基準にする。

```text

 ↓

 ↓

 ↓

```

## 17. 楽天リンク自動化

記事側では商品IDだけ指定する。

```mdx
<ProductCard id="switchbot-lock-ultra" />
```

コンポーネントが商品マスタとキャッシュを参照し、商品情報、楽天画像、価格、レビュー、楽天アフィリエイトURL、ASPリンクを描画する。記事ごとに楽天URLを手作業でコピーしない。

## 18. 商品同期

同期コマンド:

```text
npm run sync:rakuten
```

処理:
1. 商品マスタ読み込み
2. 楽天API検索
3. 商品候補照合
4. キャッシュ生成
5. エラー商品をログへ
6. ビルド

検索結果の第一候補を無条件採用しない。可能な商品は `itemCode` を固定し、未確定商品のみ検索候補を利用する。

## 19. エラー処理

楽天API失敗時:
- 前回キャッシュあり → 前回値
- 前回キャッシュなし → 楽天価格/レビューを非表示
- ASPリンクあり → ASPのみ表示
- サイト全体をエラーにしない

終売商品は削除せず販売終了状態を持ち、代替商品へ案内する。

## 20. セキュリティ

- API Access KeyをGitへ保存しない
- `.env` を `.gitignore`
- クライアントJavaScriptへAccess Keyを埋め込まない
- API同期はサーバー/CI側のみ
- 外部リンクには適切な属性を設定
- 診断では個人情報を取得しない

## 29. 最終方針

「無料だから簡易版」にはしない。インフラだけ無料とし、**見た目と利用体験は有料Webサービス相当**を目標にする。

サイトの中心は記事ではなく、防犯診断・商品検索・比較・条件別の解決導線とする。記事はそれらへ検索流入を送るSEO資産として扱う。
